# Secure Network Design and Segmentation

## Objective

Design a secure network architecture that separates users, servers, management systems, and security infrastructure.

## Design Areas

* Network segmentation
* VLAN architecture
* IP addressing and subnetting
* DMZ design
* Secure management networks
* Inter-VLAN security controls
* Firewall placement
* Redundancy and availability
* Secure routing
* Monitoring architecture

## Example

The laboratory demonstrates a segmented network using:

* User VLAN
* Server VLAN
* Management VLAN
* Security/Monitoring VLAN
* Firewall
* Core/distribution switching
