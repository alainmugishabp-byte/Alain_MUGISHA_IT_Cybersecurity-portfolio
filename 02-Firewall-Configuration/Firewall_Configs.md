# Firewall Configuration and Security Policy

## Objective

Demonstrate practical firewall administration, policy configuration, traffic control, and security validation.

## Activities

* Firewall initial configuration
* Interface and zone configuration
* Security policy creation
* Source and destination control
* Service and application filtering
* NAT configuration
* Firewall logging
* Administrative access restriction
* Configuration backup
* Policy review and optimization
* Security policy testing

## Technologies

* FortiGate
* FortiManager
* FortiAnalyzer
* Check Point

## Deliverables

* Sanitized firewall configuration examples
* Firewall policy documentation
* Network topology
* Rule review checklist
* Traffic-flow examples
* Troubleshooting procedures
* Validation and testing results
