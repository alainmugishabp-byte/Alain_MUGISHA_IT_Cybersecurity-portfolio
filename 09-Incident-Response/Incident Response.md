# Incident Response Support

## Objective

Demonstrate procedures for supporting the identification, investigation, containment, and documentation of network security incidents.

## Incident Response Workflow

```text
Detection
   ↓
Initial Analysis
   ↓
Triage
   ↓
Containment
   ↓
Investigation
   ↓
Remediation
   ↓
Recovery
   ↓
Lessons Learned
```

## Activities

* Security alert analysis
* Initial incident triage
* Log investigation
* IOC identification
* Suspicious IP/domain investigation
* Firewall event analysis
* Containment recommendations
* Incident documentation
* Post-incident review

## Threat Intelligence

The portfolio also demonstrates the use of Cyber Threat Intelligence concepts, including IOC collection, validation, correlation, and security-control integration.
